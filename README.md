## Setup

### Cloning the repository

Run the following commands

```bash
git clone https://github.com/godkama/portfolio.git
cd portfolio
```

### Installing the required packages

Run the following commands

```bash
npm install
```

### Running the project

`npm run dev` will launch a development environment. For a stable one, please run `npm run build`.
